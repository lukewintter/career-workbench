# Tag taxonomy

*(Fictional example — Firstname Lastname.)*

Tags are used in win story frontmatter to enable retrieval by theme.
Keep to this taxonomy. Do not invent new tags without updating this list.


| Tag          | Covers                                                          |
| ------------ | -------------------------------------------------------------- |
| discovery    | User research, problem definition, insight                     |
| ux           | Usability, onboarding, workflows, end-user craft               |
| delivery     | Execution, shipping, iteration, process, pace                  |
| data         | Metrics, experimentation, analytics, evidence                  |
| commercial   | Revenue, pricing, packaging, expansion, business model         |
| strategy     | Direction setting, roadmap, positioning, prioritisation        |
| stakeholders | Influence, alignment, exec comms, cross-functional buy-in      |
| leadership   | Team building, coaching, mentoring, hiring                     |


Each win story should have 2-3 tags. ATS keywords are not stored in win stories; they live in `config/targets.md` as per-track keyword banks.

Tags may evolve over time. If a win story does not fit the existing taxonomy, the agent should flag a suggested new tag to the user rather than adding it unilaterally. The user decides, updates this file, and instructs the agent to apply it retrospectively where relevant.
